# QBReader Room Locker (QBRRL)
Locks rooms, preventing players from doing literally anything.

# Usage
Copy the code from QBReaderRoomLocker.js and paste it into your DevTools console while in the QBReader Multiplayer Room (F12).<br><br>
Alternatively, copy [this](QBRRL-Bookmarklet.js) code and paste it as the link for a bookmark, and open that bookmark when you are in a multiplayer room. **This does not work in the default multiplayer rooms.**
